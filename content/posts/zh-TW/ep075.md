XPass 今天出來，我第一個反應不是看功能，是打開皮夾算：我從 Cursor 過來，額度到底變多還變少？

---

## 方案一句帶過

官方名叫 The X Subscription，大家叫它 XPass。分 Free、Plus $8、Premium $30、Super $100。Premium 是 4 倍、Super 是 15 倍，每週重置。每個付費方案都有一個 AI 額度池，Grok 和 Cursor 共用，Grok Bot 也從這一池扣，每週重置。

---

## 從 Cursor 來的人（重點）

- 方案本身不含 Claude、GPT。要用的話，Premium 以上另外照 API 牌價儲值。
- 你沒切換之前，舊的 Cursor 額度照舊，不會被動掉。
- 「額度加倍」不是整包翻倍：是每個方案的 Grok 寫程式額度，至少是對應 Cursor 方案的 2 倍。

主力用 Claude／GPT 的人要算清楚；主力用 Grok 的人比較划算。

---

## 從 Grok Build 來的人

$8 起就含 Grok Build；Bot、雲端、Bugbot 要 $30 以上。跟舊 Build 差多少，官方沒寫，我不亂猜。

---

## 誠實限制

我才剛看到，還沒用滿一個週期，實際夠不夠用還不知道；數字以官方頁為準。

---

## 最後

舊方案可以先留著，我建議大家先觀望。如果你只用 Grok Bot，共用額度池可能讓 bot 多做一些事，也可以搭配之前介紹過的，讓 bot 去協調其他工具。另外，用 Grok 模型寫程式的額度，是同等級 Cursor 方案的兩倍。

你平常寫 code 主力是 Grok，還是 Claude／GPT？留言跟我說。
