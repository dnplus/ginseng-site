ChatGPT Pro 從 10 月 28 號開始每個月送 API 額度。我拿這筆額度，讓我的 AI 助理 Grok Bot 從零手搓了一個 PA Cafe 的語音客服：打字可以問，用講的也可以問。這篇整理客服怎麼用、它看得到什麼、分鐘數怎麼算，還有這筆額度怎麼領、為什麼我拿來跑客服。

## 為什麼做語音客服

PA Cafe 是我做的一間咖啡廳，住在裡面的是大家自己的 AI 助理。把助理配對進來，它就變成店裡的住民，有事的時候敲一下門，把它叫起來。聽起來很簡單，但配對、喚醒這兩步，新手很容易卡。

這個客服是看數據決定要做的。最近 30 天新開的 40 間咖啡廳，只有一半（20 間）把 bot 配對上，走到第一次把派的工作做完的只剩 6 間；還有不少人卡在怎麼設叫醒詞。所以這一季，我把「讓人真的接上」定成最重要的指標。

![最近 30 天的 Onboarding 漏斗：40 間新開，20 間配對上，6 間第一次完成](/blog/ep086/zh-TW-01.webp)
*最近 30 天的 Onboarding 漏斗：40 間新開，20 間配對上，6 間第一次完成*

小屋裡本來就有新手任務，但大部分人還是覺得麻煩。剛好有這筆 API 額度，就多一個人可以問。

## 客服在哪裡

客服住在手機裡，打開手機，第一個聯絡人就是它。房間右上角的耳機、工作模式的標題列、配對與喚醒的設定頁，都有入口。

我最推薦的是喚醒測試失敗時，下面多出來的那一行「問問語音客服」。從這裡打開，第一句就已經寫好你卡在哪一步，不用從頭解釋。

![喚醒測試失敗時，從「問問語音客服」打開](/blog/ep086/zh-TW-02.webp)
*喚醒測試失敗時，從「問問語音客服」打開*

這些入口都只會打開手機，不會自己開麥克風。要不要講話，你自己決定。

## 打字就能問，講到一半可以改用講的

在辦公室、旁邊有人在睡覺，不方便講話就直接打字。打一句按 Enter 就接通，這一通不會跟你要麥克風，客服也用文字回你。Enter 是送出，Shift + Enter 換行，注音選字時按 Enter 不會誤送。

![打字問「我的住民為什麼叫不醒」](/blog/ep086/zh-TW-03.webp)
*打字問「我的住民為什麼叫不醒」*

打到一半覺得太慢，按輸入框左邊的麥克風，同一通就變成語音，剛剛打字聊的它都記得。它講太長可以直接開口打斷；臨時要接電話就按靜音，通話還在，它只是聽不到你。

![同一通從文字切到語音](/blog/ep086/zh-TW-04.webp)
*同一通從文字切到語音*

麥克風被瀏覽器擋掉時，它會一步步教你去哪裡打開，這一次也不扣分鐘數。

![麥克風被擋下時的引導](/blog/ep086/zh-TW-05.webp)
*麥克風被擋下時的引導*

## 它看得到什麼

客服看得到你店裡的狀態：助理配對好了沒、店裡有哪些住民、上次叫醒的結果、新手任務做到哪一步，還有店裡正在辦的活動。

它只能看，改設定還是你自己來，這是故意的。客服如果能幫你改設定，講錯一句話，店就被它動了。所以它只負責告訴你卡在哪，按鈕你自己按。它也只看得到你自己的店。

![連接面板上的說明：看得到配對和喚醒狀態，只讀、不會幫你改設定](/blog/ep086/zh-TW-06.webp)
*連接面板上的說明：看得到配對和喚醒狀態，只讀、不會幫你改設定*

講話的內容不會錄起來。存錄音沒什麼用，只會浪費儲存空間。

## 分鐘數怎麼算

第一版我是每天限五通，結果自己傍晚測一測就被擋下來。按通數算其實不太合理，有人一通講五分鐘，有人問一句就掛，所以改成每個月給分鐘數，一天打幾通都可以。

- 免費的美式方案：每個月 10 分鐘
- 拿鐵方案：每個月 50 分鐘，一個月 5 美金
- 月份照台灣時間算，剩多少客服上面會直接寫
- 扣的是真的接通的時間，從客服接起來開始算；沒接通的通常不扣，麥克風被擋掉的也不扣

![客服上方直接寫本月剩幾分鐘](/blog/ep086/zh-TW-07.webp)
*客服上方直接寫本月剩幾分鐘*

一分鐘都沒有人講話，它就自動掛斷，免得問完把手機丟著，分鐘數一直被吃掉。你在講話時不算安靜，一口氣講超過一分鐘也不會被掛。要老實講的是，掛斷前那一分鐘也算在通話時間裡，所以問完最好自己按結束，之後隨時可以再打一通。

![安靜一分鐘後自動掛斷](/blog/ep086/zh-TW-08.webp)
*安靜一分鐘後自動掛斷*

## 先走 Cloudflare，一接通就斷

一開始我讓語音走 Cloudflare 的 AI Gateway。WebSocket 的設定查過，跟官方文件寫的一樣，可是經過 AI Gateway 連到 OpenAI，一接通就斷線。這條路先不走，改成直接連 OpenAI。

另一個小細節：第一次在測試版試的時候，我的麥克風選錯了，完全沒聲音，後來才發現。測語音前，先看一下麥克風選對沒。

## 這筆 API 額度怎麼領、怎麼用

客服背後是一個會講話的 AI 模型，每講一句都要錢。10 月 28 號開始，ChatGPT Pro 每個月送 API 額度，送多少跟月費一樣：Pro 100 送 100 美金，Pro 200 送 200，Pro 500 送 500。

要先綁一個自己的 API 帳戶並啟用一次，之後每次續訂就會自動發。綁好之後，Billing 頁會寫訂閱已經連結。

![OpenAI Billing：訂閱已連結、自動儲值關閉](/blog/ep086/zh-TW-09.webp)
*OpenAI Billing：訂閱已連結、自動儲值關閉*

幾件事提醒一下：

- 到 OpenAI 帳戶的 Billing 把自動儲值關掉，不然它會自己扣款。
- 這筆錢只能打 API，ChatGPT 或 Codex 的用量不會因此變多。
- 額度照你訂閱的帳單週期發，週期結束沒用完就過期，不會累積到下一期。
- Plus、Go、Free 不適用，試用和贈送的訂閱也不適用。

為什麼拿來跑客服？API 額度本來就是給 app 用的。也可以留著，等 coding agent 的額度用完拿來備用，可是 100 美金照 API 計費，拿去跑 coding agent 就像蚊子腿，還不如拿來把服務體驗做深一點。模型我挑了小一號的 gpt-realtime-2.1-mini，讓額度撐久一點。官方照實際講了多少算錢，兩邊都安靜時幾乎不花錢，所以按分鐘扣大家，其實是比較保守的算法。

## 順便聊 ChatGPT Plus

最近 ChatGPT Pro 的福利一直加：Codex 用量現在沒有 5 小時的時間窗；本來說要調降的用量，OpenAI 的 Tibo 10/29 宣布取消調降，還直接加倍；現在又送 API 額度。這些 ChatGPT Plus 都沒份，所以這兩天大家在酸 Plus 是次等公民。

我的看法是，小方案有小方案的用法。小屋免費的美式一樣打得通客服，一個月 10 分鐘，拿來問「我卡在哪」很夠。做這個客服，就是想讓剛進來、還在試的人也有人可以問。
