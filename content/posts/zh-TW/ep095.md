## 永豐被罵翻的這週

11 月 3 號，永豐銀行的新網銀被盜轉。四百多位客戶，大多一個人被轉走 10 萬，我看到的留言幾乎罵翻了。這篇我想逆風一下，替永豐講幾句話。

![自由財經 11/3 的標題：金管會說 419 人受影響，總金額約四千多萬](/blog/ep095/ltn-419.jpg)

先講我自己。大概 2015、16 年，我在串群益的 SKCOM。它是 Windows 的 COM 元件，Python 要透過它去呼叫，那段串得我很想死。你可能會問，怎麼不乾脆寫 C# 或 VB？那時候沒有 AI 幫忙，我就是看 Windows 不順眼。

![群益 API 的 Python 包裝 skcom，說明寫著只相容 Windows 64 位元](/blog/ep095/skcom-windows.jpg)

後來永豐出了 Shioaji，一套 Python 的下單工具，Mac 跟 Linux 都能跑，我就去開了永豐的戶。

這篇先從事件講起，最後聊一件事：台灣很難接受失敗，可是新東西本來就帶著風險。

## 11 月 3 號發生什麼事？

11 月 3 號早上 9 點半，永豐客服開始接到電話，客戶說帳戶裡的錢被轉走了。半小時內就來了快十通，銀行判斷是一批人同時出事。

總共 427 筆、418 位客戶（金管會的數字是 419 人），大部分一筆 10 萬，加起來四千多萬，全部轉進同一個北富銀的帳戶，這個帳戶已經凍結。永豐的說法是，新網銀交易系統的國外供應商，安全設定有漏洞，駭客跳過了驗證。金管會說，原因還在調查。

這一段該罵。系統是永豐自己選、自己上線的，總經理也承認，這次導入時的測試和設定交接有例外。客戶把錢放在銀行，出事就是銀行的責任。

## 它怎麼處理？

照永豐記者會公布的時間：

| 時間 | 做了什麼 |
| --- | --- |
| 9:29 | 客服接到第一通電話 |
| 10:30 | 凍結收款帳戶 |
| 中午 | 決定不管調查到哪，先還錢 |
| 12:50 | 通報金管會 |
| 13:47 | 下架新網銀 |
| 14:51 | 錢全部退回客戶帳戶 |

從第一通電話到退款，大約五個多小時。

隔天董事長和總經理出來鞠躬道歉，錢先由銀行扛，再去向供應商求償。金管會要它七天內交調查報告，要不要罰，金管會說看完報告再決定。

![今周刊報導 11/4 記者會，永豐董事長、總經理鞠躬道歉](/blog/ep095/bt-apology.jpg)

## 五個多小時，算快還是慢？

資安業界常用兩個指標：

- **MTTD**（Mean Time to Detect）：從出事到發現要多久。
- **MTTR**（Mean Time to Respond）：從發現到處理好要多久。

IBM 2025 年的報告，資料外洩從被入侵、發現到圍堵，加起來平均 241 天。

駭客什麼時候開始試，我查到的報導都沒寫，所以只能比發現之後的那一段。日本小七的 7pay 在 2019 年被盜刷，從有人反映到停掉所有儲值，大約兩天。永豐從第一通電話到下架新網銀，四個多小時，下午三點前錢就全部退回了。

## 永豐這幾年推了什麼？

### Shioaji：能在 Mac、Linux 跑的 Python 下單 API

先從我最熟的講。Shioaji 的 GitHub 是 2018 年 11 月開的，PyPI 上最早查得到的版本是 2019 年 1 月，`pip install shioaji` 就裝得起來。

![Shioaji 的 GitHub 頁面，repo 裡有 Dockerfile，標籤寫著 cross-platform、docker、python](/blog/ep095/gh-shioaji.jpg)

![PyPI 的版本紀錄，最早的 0.0.4.dev3 是 2019 年 1 月 29 日](/blog/ep095/pypi-2019.jpg)

之前的 README 寫過，它是台灣第一個能在 Linux 跟 Mac 上跑的 Python 交易 API；現在的版本則寫，它是台灣第一個支援 AI coding agent skill 的交易 API。

對寫程式的人，影響很大。訂閱報價本來就是非同步，資料一直推進來，用 Python 跨過去接 COM 元件常常不穩。我試過幾種繞法：硬包成同步的命令列工具、中間架一台 RabbitMQ 轉接；歷史報價格式比較單純，我乾脆逆向，直接從 socket 接，省了不少事。

而且綁死 Windows，想做成容器丟上雲都很麻煩。Shioaji 可以直接跑在 Linux 上，repo 裡也有 Dockerfile。我就是因為這樣，才換到永豐的。

### 大戶 DAWHO：2019 年上線的數位帳戶

數位帳戶大戶是 2019 年 6 月上線的，在它之前，市場上已經有二十幾個數位帳戶。永豐金證券贊助的一篇數位時代專題寫，它第三年損益兩平，第四年開始賺錢，到 2025 年 9 月底超過 211 萬戶。

![數位時代（永豐金證券贊助）：DAWHO 第 3 年損益兩平、第 4 年獲利，2025 年 9 月底戶數突破 211 萬](/blog/ep095/bnext-dawho.jpg)

### 銀行跟證券一次開五個帳戶

它也把銀行跟證券綁在一起。2021 年 11 月推出，網頁上一次申辦五個帳戶：台幣、外幣、信託、台股、複委託，銀行和證券兩家公司一次開好。

### 其他小地方

- **房貸**：2017 年的房貸平台能線上彈性繳款，永豐自己說是業界首創。
- **信貸**：數時貸線上簽約，官網寫最快 10 分鐘撥款。
- **抽股票**：大戶投有智慧申購，條件設好，系統自己幫你抽。

我自己抽籤、借錢、辦卡，幾乎都在手機上弄完。

還有大戶卡。永豐合作邀稿的文章寫，2026 年改成全通路，一般消費不用挑通路就有加碼，放到大戶等級，國內最高 3.5%，加碼每個月有上限。網路上的信用卡文章，直接叫它無腦卡。

## 做越多，風險越多？

把這些擺在一起看，會發現一件事：每推一個新東西，就多一個可能出事的地方。新網銀也是新東西，這次出事的，剛好就是它。

台灣對失敗很不寬容。我看到的反應，常常是一出事就要有人下台、要重罰。銀行也會學：最安全的做法，就是什麼新的都別做，舊系統一直用，反正沒有人會因為沒創新被罵。

最後吃虧的是用戶。Shioaji、數位帳戶、線上開戶，這些方便，都是有人願意先做才有的。這次新網銀出事，照永豐的說法，問題出在導入時有例外，這一塊要檢討；願意推新東西的那股勁，我希望留著。

事件隔天，金管會副主委莊琇媛在資安論壇點名了幣安和永豐。她說，資安的考驗，看的是能不能迅速控制、在最短時間恢復服務、保障客戶權益，也要用「假設已經被入侵」的思維檢查防線。我覺得這個方向對。

![LINE TODAY 轉太報：金管會副主委莊琇媛在 11/4 資安論壇點名幣安、永豐銀事件](/blog/ep095/fsc-line.jpg)

所以該盯永豐的，是後面這三件：

1. 供應商交接為什麼會有例外。
2. 七天的調查報告寫了什麼。
3. 新網銀下次上線前怎麼驗。

這幾件做得好，我覺得可以再給它一次機會。

## 整理

- 新網銀出事，導入時的例外要檢討，原因要等金管會調查完。
- 處理上，永豐五個多小時就把錢還給客戶。
- 這家不在前五大的金控，這幾年一直在推新東西。

你覺得呢？銀行出過一次包，你會讓它繼續試新東西嗎？到影片下面留言跟我說。
