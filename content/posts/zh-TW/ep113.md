## 誰早就佔好位了

大家天天在猜哪家 AI 模型會贏。但如果「注意力」才是最後最值錢的東西，位子最好的五家其實早就佔好了：

- 社群那邊：YouTube、X、Meta
- 企業那邊：微軟、Amazon

這五家裡面，受益最大的，我認為是 YouTube 背後的 Google。

**這套說法從 coding agent 出來講到現在，為什麼當初沒人有感覺，到了今天突然全都懂了？**

這篇先用最基本的供需，白話拆這兩年寫程式的日常怎麼變的；再看這五家各卡在哪裡；最後講為什麼是 Google。它本來就是賣注意力最多的一家，Gemini 4 重返御三家之後，Google 變成唯一兩頭都抓的玩家。

## 為什麼現在才真的懂

### 兩年前：一個視窗，問一句答一句

兩年前剛用 AI 寫程式，大部分人開一個視窗，問一句答一句，寫完貼回去。那時候大家覺得自己變快、省下很多時間，聽到有人喊「以後瓶頸是人的注意力」，只覺得這句話好抽象。

### 現在：被切成一格一格的一天

現在你同時開三四個 coding agent 在跑，叫它寫功能、跑測試、改版面。它跑的這兩分鐘，你做不了需要專心的事。有人去看另一個 agent，有人回訊息，也有人滑一下社群。手上的事還沒弄完，叮咚，第一個跑完要你按核准，看一堆 diff，腦袋又要切回來。打字省下來了，專注力整天被切成一格一格。

### 我自己的紀錄

這個感覺我拿自己的紀錄數過。我把電腦裡 Codex 跟 Claude Code 的工作紀錄撈出來，統計 2026 年 10 月 22 日到 11 月 21 日這 31 天：

| 指標 | 數字 |
| --- | --- |
| 一天開的工作階段，中位數 | 13 個（連 agent 自己再開出去的也算） |
| 最忙的五分鐘裡，同時有動靜的工作階段，中位數 | 6 個 |
| 最誇張那天，同時有動靜的最高數字 | 21 個 |

六個 agent 輪流跑完、輪流回來找我，我的一天就是這樣被切開的。

### 兩種成本一起漲

**閱讀與判斷的成本。** 以前自己寫的程式，每一行的理由我都記得；現在 agent 一次丟回來幾百行 diff，我得先看懂它做了什麼，才有辦法判斷對不對。打字的力氣省下來，換成閱讀跟判斷的力氣花出去。

**切換的成本。** 你正在想 A 功能的資料表怎麼切，B 跑完叫你；看完 B 的 diff 再回來，A 想到哪裡要從頭讀一次。開兩個 agent，一小時可能重讀三四次；開到六個，一整個下午都在重讀自己剛剛想過的東西。

### 最基本的供需

以前寫一個工具要花好幾週，現在一個下午就能讓 AI 生出來，程式、文章、影片都一樣。做東西的成本掉下來，供給就暴增。看東西的那一邊呢？每個人一天還是二十四小時。

所以回到開頭的問題：為什麼當初沒人有感覺，到了今天突然全都懂了？因為東西多到看不完以後，缺的就換成注意力。對內，你自己的注意力變成驗收瓶頸；對外，別人的注意力變成最難搶的門檻。

## 社群三家卡在什麼位子

看懂供需怎麼變，再回頭看誰佔著好位子，畫面馬上清楚。先看個人跟社群這一邊：YouTube、X、Meta。大家的注意力本來就有一大塊放在這三家，它們賣的就是這個。

供給暴增以後，它們吃到兩塊紅利：

1. **零碎時間**：幾分鐘的空檔，最容易被短內容填掉。
2. **能見度**：產品跟內容大爆發之後，誰決定你能不能被看見。

### Meta

Meta 2026 年第三季財報公布，旗下 Facebook、Instagram、WhatsApp 這一整家 App，平均每天活躍人數是 36.4 億人。地球一半的人每天滑它的介面，朋友跟家人都在裡面。你今天用 AI 半天寫出一個超好用的工具，想找陌生人來用，最後多半還是要跟它買廣告。模型誰當第一都會換人，收過路費的路口一直在它手上。

### YouTube

Alphabet 2026 年第三季財報，YouTube 單季廣告營收 112.1 億美元，Music 跟 Premium 訂閱合計破 1.5 億，含試用。YouTube 官方 2024 年就講過，全球觀眾每天在電視上看掉超過 10 億小時。

對工程師來說更直覺：等 agent 跑的時候開著當背景音，想學新工具直接上去搜。AI 生成的雜訊越多，大家反而越只看固定信任的真人頻道。

同一篇 2024 年的官方文章還有另一個數字：主要觀看時間落在電視上的頭部創作者，數量增加超過 400%。它已經從手機上的零碎時間，一路吃到客廳那台電視。零碎時間有短影片接，下班攤在沙發上的那兩小時有電視接。

![YouTube 官方部落格：每天電視觀看超過 10 億小時，電視為主的頭部創作者增加超過 400%](/blog/ep113/yt-tv.png)

*YouTube 官方部落格（2024-02-20）：全球觀眾每天在電視上看超過 10 億小時，主要觀看時間落在電視的頭部創作者增加超過 400%。*

### X

X 私有化以後沒再發公開季報，前任執行長之前公開提過大約 5.4 億月活。規模比前面兩家小，但 AI 圈跟技術圈幾乎全擠在這裡。新模型發佈、踩坑討論、開源專案首發，第一時間全在 X 上刷。技術人有零碎時間想看同行在聊什麼，多半就開它。更狠的是它把自家的 Grok 直接接進動態流，看貼文順手就問完。

xAI 手上除了動態流，還有前面提到的 Grok Bot。官方公告說，他們內部常常一次開好幾個 Bot 平行跑，上面再放一個當幕僚長管其他的。一邊是技術人看消息的 App，一邊是幫你跑 agent 的工具，兩頭接的是同一個 Grok。

![xAI 公告：同時跑多個 Bot，上面放一位幕僚長管理其他 Bot](/blog/ep113/grokbot-chief.png)

*xAI 〈Introducing Grok Bot〉：內部常平行跑多個 Bot，由一位 chief of staff 管理其他的。*

### 三家合起來看

用生產跟消費來看：

- 你當**消費者**的時候，時間花在它們那裡。
- 你當**生產者**的時候，做出來的東西要被陌生人看見，也要經過它們的推薦跟廣告版位。

AI 讓做東西的人跟東西的數量一起暴增，每個人一天還是只有二十四小時，版位就那麼多，搶的人變多，價格自然往上走。

## 企業兩家卡在什麼位子

社群三家吃掉的是下班時間跟空檔注意力，那上班那八小時呢？企業端看的是另一種位子：員工每天開機就盯著哪塊螢幕，還有公司的資料、合規跟帳單原本綁在哪裡。這塊佔最穩的是微軟跟 Amazon。

### 微軟：員工眼前那塊螢幕

官方今年財報揭露，Microsoft 365 商業付費席次超過 4.5 億，GitHub Copilot 用戶也跨過 5,000 萬。你把它想成公司發給每個員工的預設辦公桌：早上一開機就是 Windows、Teams、Outlook，工程師打開就是 VS Code 跟 GitHub。

7 月的財報會議還補了幾個數字：

- Microsoft 365 Copilot 的付費席次超過 3,000 萬，單季新增的席次比前一季多一倍以上。
- 把 Copilot 部署給大多數知識工作者的企業客戶，單季成長將近 75%。

4.5 億個辦公桌裡才開了 3,000 萬，後面還有很長的路可以賣。

### Amazon：螢幕後面的資料跟帳單

Amazon 2026 年第三季財報，AWS 單季營收衝到 460 億美元，年增將近四成，換算年化規模 1,840 億美元。很多企業的資料庫、權限、主機跟既有採購合約本來就住在 AWS 上面。公司想讓 AI 真的接進內部系統做事，留在原本的雲端底座跟合規框架裡阻力最小。另外消費端大家真要刷卡下單時，亞馬遜還握著商品跟物流履約，這塊一樣很難繞開。

### 兩家合起來

微軟佔的是員工眼前那塊螢幕，Amazon 佔的是螢幕後面的資料跟帳單。agent 要在公司裡真的做事，一邊要出現在員工看得到的地方，一邊要拿得到資料跟權限，這兩樣剛好各在一家手上。

### 回到開頭：模型 vs 入口

大家天天猜哪家模型會贏。模型當然重要，Google 也是靠 Gemini 4 追上來才有今天這張表。只是模型每隔幾個月就換一輪排名，使用者每天打開哪個 App、公司的資料放在哪朵雲，好幾年都換不掉。

## 做產品的人怎麼看這件事

你今天用 AI 做出一個工具，功能上很難領先別人多久，因為別人一個下午也做得出來。那使用者為什麼選你？多半因為他本來就在那個地方：他已經開著的視窗、已經在用的帳號、已經追蹤的人。

### 做東西之前先問兩個問題

1. 使用者要多開一個視窗才用得到，還是在他本來就開著的地方就能用？
2. agent 做完之後怎麼回報？丟一長串紀錄要人自己翻，還是只在需要人決定的時候才叫他？

### 沒有入口的小團隊

小團隊沒有自己的入口，可以先長在別人的入口上：做成瀏覽器擴充功能、Slack 或 Teams 裡的 bot、GitHub 上的 App，使用者在原本的地方就碰得到你。等他習慣每天叫你做事，再來談要不要請他多開一個視窗。

### 把人叫回來的次數要省著用

你的工具如果老是跳通知、每一步都要人按確認，使用者的注意力被你吃光，他下次就不想開了。Grok Bot 那句「需要核准才回來」，跟 Chrome 自動瀏覽的檢查點，講的都是同一件事：把人叫回來的次數要省著用。

## 大 I 人在這時代有多吃虧

當寫程式變便宜、注意力變最貴，有一群人我覺得特別吃虧，就是像我這種 INTJ 大 I 人。

11 月 12 號，Y Combinator 第一次來台灣辦 Startup School Taipei，要人工逐件審查才會過。我運氣不錯有選上，也真的跑去現場。整場活動聽完，滿場都是很猛的開發者跟創辦人，我呢？半個人也沒認識。

回家之後我就在想這件事。以前工程師覺得埋頭把系統寫好、把架構磨漂亮就夠了。現在大家開幾個 coding agent 都能快速交出東西，像我這種現場開不了口換名片的大 I 人，如果不找個方式讓人記住自己，東西做得再認真，別人根本連點都沒點進來。

### 一張名片，替我開口

好笑的是，PA 小屋的名片功能，就是我當天早上趕出來的。名片頁上寫著「技術社畜、總之就是喜歡瞎折騰」，旁邊列著五位 AI 住民、合併快兩千個 PR，還有留訊息的入口。

![PA Cafe 的名片頁：五位 AI 店員、1127.4 億 tokens、1955 合併 PR、256 天活躍](/blog/ep113/pacafe-card.jpg)

*PA Cafe 名片頁：5 位 AI 店員、1127.4 億 tokens、1955 合併 PR、256 天活躍。*

結果名片做好了，我整場沒找任何人聊，一次也沒亮出去。回頭想，名片該做的事跟前面講的供需是同一件：對方的注意力很缺，只肯花幾秒決定要不要認識你，名片就是幫他把這幾秒要看的東西先排好。現在這張放在網路上，我開不了口的時候，讓它替我開口。

## 自己的注意力怎麼顧

我整理四個做法：

1. **交代任務時把話講完整。** 要做什麼、做到什麼算完成、哪些事它可以自己決定。交代得越清楚，agent 中途回來問你的次數越少，你被打斷的次數也跟著少。
2. **把核准集中處理。** agent 跑完先讓它排隊，你固定一個時間一次看完，像收信一樣一批一批清。每次叮咚就切過去看，等於把一整天的專注力拿去換零錢。
3. **等待的那兩分鐘，先想好要拿來幹嘛。** 可以去看另一個 agent 的結果，可以把下一個任務寫好，也可以單純起來倒杯水。沒先想好，這兩分鐘很容易被最順手的東西填掉，回來的時候剛剛想到一半的東西要重新接。
4. **能交給 agent 驗的就讓它自己驗。** 讓它跑測試、自己截圖對照、把結果整理成三行，你只看結論跟有問題的地方。你的注意力最貴，留給它真的決定不了的事。

### 拿自己的紀錄來對

這四個做法要用到什麼程度，可以拿自己的紀錄來對。像我前面數出來，同時在動的中位數是 6 個；你也可以把自己的工作紀錄撈出來，看哪幾天開最多、那幾天的東西有沒有漏看。數字擺出來，比憑感覺說自己很忙準很多。

### 小工具：urai

懶得自己撈紀錄的話，我做了一個小工具 [urai.dnplus.dev](https://urai.dnplus.dev/)。把指令交給本機的 Claude Code、Codex 或 Cursor，它會抽樣你最近 60 天的對話紀錄，原文跟程式碼全留在你電腦、不上傳，再借用 16 型四碼命名，幫你抽一張角色閃卡，看你帶 agent 是哪一型。判斷方式見[這一頁](https://urai.dnplus.dev/method)。

![urai 首頁：你的 Agent，是哪種夥伴風格？](/blog/ep113/urai-home.jpg)

*urai.dnplus.dev：讓你的 Agent 讀完你們的對話，說說你是哪種搭檔。*

卡上的稀有度，看的就是你用 AI 的成熟度：

- **稀有**：會確認 agent 的結果、出錯指得出來。
- **史詩**：寫下的技能跟規則被其他工作再用到。
- **傳說**：自動化穩定跑兩週以上。

![urai 稀有度說明：普通到稀有看是否確認 Agent 結果，史詩看技能規則是否被重複使用，傳說看自動化是否穩定運作兩週以上](/blog/ep113/urai-rarity.png)

*urai 的稀有度說明：看你是否確認結果、技能是否被重複使用、自動化是否穩定運作兩週以上。*

如果你已經抽到傳說，恭喜，你自己注意力的問題應該緩解一大半了。

## 看懂之後，自己怎麼留位子

看懂「注意力變最貴」這件事，一般技術人能做兩件事：

- **對內**：管好你開 agent 的節奏，等待的那兩分鐘先想好要做什麼，把腦力留給定義問題跟最後驗收。
- **對外**：把「做出來」當成基本功，多留一個讓別人認識你的低摩擦入口，不管是拍片、寫文章、放開源，還是做一張像小屋名片這樣的門面。

你現在同時開幾個 coding agent？等它跑的時候你都在做什麼？歡迎留言跟我說。
