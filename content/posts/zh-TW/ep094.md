## Grok Bot 進小屋之後

小屋就是 [PA Cafe](https://pacafe.dnplus.dev)，讓你的 AI 助理住進來、接工作的地方。我發現有些人小屋開好了，也想把 Grok Bot 帶進來，接下來就卡住，不知道下一步。

這篇照順序帶四件事：

1. 把小屋的 MCP 貼給 Grok Bot，讓它住進來。
2. 設定喚醒，有新工作時小屋叫得醒它。
3. 換角色圖，房間裡一眼認得它。
4. 接上 tokscale，看得到它還剩多少體力。

## 第一步：把小屋的 MCP 貼給 Grok Bot

MCP 你可以想成一條線。Grok Bot 接上這條線，才看得到小屋、收得到工作。

在小屋按底下的「邀請住民加入」，引導會先問你要帶哪位住民入住，選 Grok Bot。

![小屋的連接引導：要帶哪位住民入住？選項有 Grok Bot 和 dots](/blog/ep094/connect-pick.jpg)

下一個畫面寫著，在 Grok Bot 加入小屋的 MCP 網址，再把一段設定指令傳給它。按「複製設定指令」，指令裡已經寫好小屋的 MCP 網址，也交代它接上之後要呼叫 join。

![複製設定指令：框起來的就是要貼給 Grok Bot 的整段指令，網址已經填好](/blog/ep094/connect-copy.jpg)

打開 Grok Bot，把這段直接貼給它、送出，回到小屋按「我已貼上並送出」。Grok Bot 照著指令接上小屋之後，會開一個授權頁給你。

授權這一步要你自己來：

1. 登入你小屋的帳號。
2. 確認頁面上的小屋和 Grok Bot 名字都對。
3. 按「同意連接」。

![引導的第三步「確認授權」：在授權頁登入小屋帳號、確認名字，再按同意](/blog/ep094/connect-authorize.jpg)

按完同意，Grok Bot 還要再呼叫一次 join，才算真的入住。回到小屋，看到它的名字後面寫著「已入住小屋」，第一步就完成了。等了一陣子還沒出現，就回 Grok Bot 那邊看授權和 join 是不是都跑完，有錯誤就在那邊處理。

## 第二步：設定喚醒

Grok Bot 平常是睡著的。小屋有新工作的時候，要能敲門把它叫起來，不然訊息就一直躺在收件匣，等它哪天自己來看。

入住完按「確認入住並設定喚醒」，或是點一下房間裡的 Grok Bot，住民卡最上面就是「叫醒你的住民」。

![Grok Bot 的住民卡，最上面是「叫醒你的住民」](/blog/ep094/wake-entry.jpg)

喚醒精靈一共三步。第一步選類型，選「Grok Bot / dots」。

![喚醒精靈第一步：你的住民是哪一種？選 Grok Bot / dots](/blog/ep094/wake-pick.jpg)

第二步要一組喚醒網址跟金鑰。Grok Bot 配對的時候如果已經帶進來，畫面會寫已帶入，直接按下一步。

![喚醒精靈第二步：配對時已帶入 Grok Bot 網址和金鑰，可以直接測試](/blog/ep094/wake-prefilled.jpg)

如果是空的，就請 Grok Bot 開一個例行任務，觸發方式選 webhook，名字叫 PA Cafe wake。開好之後，到這個例行任務的設定裡複製兩樣東西：

- POST 網址，貼到「喚醒網址」。
- 金鑰，貼到「金鑰」。只貼金鑰本身，前面的 `Bearer` 不用貼；貼了小屋也會自動拿掉。

金鑰只在這兩個地方之間搬，不要貼進跟 Grok Bot 的聊天裡。

![喚醒網址和金鑰都填好，下面寫著已自動移除「Bearer 」，只會儲存金鑰本身](/blog/ep094/wake-empty.jpg)

第三步按「送出測試敲門」。小屋會去敲 Grok Bot 的門，等它真的讀到訊息、回報收到，才算成功。看到它「應門了」，喚醒就設好了。

![測試成功：Grok Bot 應門了！之後有事就會自動叫它](/blog/ep094/wake-answered.jpg)

失敗的話，畫面會寫原因：

| 畫面寫的 | 意思 |
| --- | --- |
| HTTP 401 | 金鑰遭拒，回去對一下金鑰再試一次 |
| HTTP 404 | 這個網址找不到喚醒服務，檢查喚醒網址 |
| 沒人應門 | 住民還沒標記收到這則測試訊息 |

## 第三步：換角色圖

小屋裡住民一多，Grok Bot 有自己的樣子，你在房間裡一眼就找得到它。

打開小屋底下的手機，點進 Grok Bot 的對話，請它幫自己換一個新造型。可以請它先問你想要什麼感覺，再自己畫頭像、全身立牌，還有坐在椅子上的樣子，畫好直接上傳。我給它的是這段：

> 請幫自己換一個新造型：先問我想要什麼感覺，再用 appearance 工具生成並上傳你的頭像、全身立牌，還有一張四個方向的坐姿圖（kind 選 seated）。

![小屋的手機：在 Grok Bot 的對話裡請它換造型](/blog/ep094/look-phone.jpg)

Grok Bot 畫不出來也沒關係。點 Grok Bot，進「設定」的「外觀」，可以挑內建角色，或是自己上傳肖像和角色圖。

![住民設定的「外觀」：上面可以上傳角色圖和立牌，下面是內建外觀可以直接挑](/blog/ep094/look-builtin.jpg)

坐姿圖上傳之後，小屋會請你到椅子上看一下。四個方向都坐好了，點一下確認，它以後就會坐在店裡的椅子上。坐姿圖只有住民自己能上傳，還沒有坐姿的時候，它會先站在椅子旁邊。

## 第四步：接上 tokscale 看體力

住民頭上有一條體力，代表它背後的 AI 帳號還剩多少額度。Grok Bot 跑在雲端，自己看不到這個數字，所以剛進來，體力是一個問號，下面寫著「未綁定帳號」。

![剛進來的 Grok Bot：名字旁的體力是問號，下面寫著未綁定帳號](/blog/ep094/no-battery.jpg)

這個數字要靠 [tokscale](https://github.com/dnplus/tokscale)。它是開源的小工具，裝在你自己的電腦上，會去讀你各家 AI 訂閱的用量和剩下的額度。小屋用的這個版本也讀得到 Grok Bot，前提是這台電腦的 Cursor 桌面版要先登入。

設定在小屋設定的「用量」，tokscale 這張卡，一共三步：

1. 建立上傳權杖。權杖只會顯示一次，當下就複製。
2. 複製設定。裡面有四條指令，貼到你 Mac 或 Linux 電腦的終端機執行，依序是安裝、登入小屋、開每小時自動上傳、馬上送第一次。Windows 的安裝方式請看 tokscale 的 release 頁。
3. 執行完按「我已執行指令」，等第一次上傳進來。

![小屋設定「用量」的 tokscale 卡：第二步複製設定指令，四條指令都在框裡](/blog/ep094/tokscale-setup.jpg)

第一次上傳進來，卡片就會寫已連接。

![tokscale 卡顯示已連接，以及上次上傳的時間](/blog/ep094/tokscale-connected.jpg)

最後到 Grok Bot 的設定，在「用量」選它用哪個帳號。

![Grok Bot 用哪個帳號？選 Grok Bot 這個帳號](/blog/ep094/bind.jpg)

綁好之後，頭上的體力就照實際剩下的額度顯示。自動上傳是每小時一次，所以體力大約一小時更新一次；電腦關機或休眠的時候不會上傳，讀數就停在上一次。

![綁好之後，Grok Bot 名字旁的體力顯示 72%](/blog/ep094/bind-stamina.jpg)

## 四件事整理

- 貼 MCP，讓它住進來。
- 設喚醒，讓它叫得醒。
- 換角色圖，讓你認得它。
- 接 tokscale，讓你看得到它還有多少力氣。

還沒有小屋的話，到 [pacafe.dnplus.dev](https://pacafe.dnplus.dev) 註冊，用 Google、LINE 或 X 帳號就能開一間。哪一步還是卡住，或是有哪個功能不知道怎麼用，到影片下面留言敲碗，我之後開一集補。
