DevDay 那幾天，我最在意的不是新模型，是有沒有 reset。結果 reset 還沒等到，先收到一封通知：**62,500 credits**。這篇把 DevDay 我覺得最值得看的五件事拆給你看：dots、MCP Events、Decisions API、GPT-6.1 Sol，還有把 ChatGPT 方案帶去別的 App。順便把一件很容易搞混的事講清楚：**點數、reset、方案用量是三份不同的東西**，你的工作從哪一份扣，會決定這些新功能怎麼用才划算。

> 🎬 影片：[OpenAI撒錢？！收到\$2500點數](https://youtu.be/kAvbqlc4OUQ)

## 62,500 點，大概是 2,500 美元的用量

通知上寫的是 62,500 credits，用在 ChatGPT Work 和 Codex，期限到 2026 年 12 月 31 日。看到這個數字，我真的很驚訝，OpenAI 這次也太大方。

換成美元怎麼算？OpenAI 在 Codex 學生方案的說明裡寫過：**2,500 credits 相當於 100 美元**。照這個比例，62,500 點大約是 **2,500 美元**的用量。

[Codex for Students](https://developers.openai.com/community/students)

這些點數是讓你繼續工作用的：方案內含的用量先扣，用完之後才從點數扣。它不能換現金，也不是 API 錢包。

[Using credits for flexible usage in ChatGPT](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-personal-plans)

點數我收到了。但我開場問的 reset，是另一回事。

## Reset 不是點數：一個往下扣，一個重新刷新

你可以把 **banked reset** 想成先存著的一張重設券。帳號有拿到的話，可以在到期前自己挑時間用。點數是往下扣的；reset 是把用量直接刷新。這個機制 DevDay 之前就有了，不是這次的新品。

用 **Full reset** 會刷新 5 小時和每週兩個用量窗口，而且**週重設日會跟著改**。官方的例子：原本週五重設的人，週二先用 Full reset 再繼續用 Codex，下次重設就變成下週二左右，原本那個週五不會再多送一輪。另外，它只有真的刷新到用量才會被用掉，沒東西可刷就留著。

[How banked Codex resets work](https://help.openai.com/en/articles/20001498-how-banked-codex-resets-work)

Plus 和 Pro 個人帳號還能付費買 **instant reset**。它跟 banked reset 最大的差別是：**買了立刻生效，不能存**。它是把原本每週的額度提前拉過來，不是額外多給一份；新的一週從套用後的第一個請求開始算，七天後才是下一次自動重設。

[Paid weekly Work and Codex rate-limit resets](https://help.openai.com/en/articles/20001507-paid-weekly-work-and-codex-rate-limit-resets)

所以我在意的問題很實際：工作卡在上限時，手上有沒有一張現在能用的 reset。能不能領、領到哪種、哪天過期，打開自己帳號的 Settings → Usage 看。既然用了會重算週期，原本的週重設只剩一天時，就不急著用。

## dots：交代目標，它自己往下做

先講一個好笑的：你在瀏覽器打 [dot.com](http://dot.com)，現在會被轉去 Grok Bot。OpenAI 發 dots，網址卻幫隔壁帶客。

**dots** 是 ChatGPT 裡一位能持續工作的 AI 同事，背後是 GPT-6 Astra。你交代一個目標，它記得這件事，用自己的雲端電腦、自己的瀏覽器，加上你連接的 App 繼續做。你離開之後，它還會追進度、把成果帶回來。

開放範圍：Pro、Business Premium 依地區逐步開放，方案已包含第一個 dot；Enterprise（含 Edu、Healthcare）要工作區管理員開啟 beta。

OpenAI 舉的創作者例子我一看就懂：新的訪談逐字稿進來，dot 挑出適合剪短片的段落、整理節目筆記、寫社群貼文草稿，然後**停在「還沒發布，等你審」**。創作者看完，還能直接叫它保留某張照片、把文案縮短，再看改過的版本。做內容常常是一集錄完，後面還拖著好幾份東西要整理。dot 吸引我的地方，是它能記得那套做法，持續準備下一批。

工程師的例子是同一個邏輯：dot 留意客戶回饋裡反覆出現的問題，整理修正範圍、改程式、跑測試，最後帶回一個**附影片的 PR** 讓工程師 review。改了什麼、怎麼驗證，人可以接著檢查，這就是交付物。

還有一條跟用量有關：**跟 dot 聊天不計入 ChatGPT 的用量限制**；但你請它在 Codex 或 ChatGPT 工作裡啟動任務，那些任務照常計入。

[dots 正式登場](https://openai.com/zh-Hant/index/introducing-dots/)

## MCP Events：有事情發生，才開工

dot 講的是誰在做事；**MCP Events** 講的是什麼時候開始做。它像門鈴，有人來才響：App 裡出現新事件，支援事件的外掛就通知 ChatGPT，啟動你事先設定好的工作。

DevDay 官網舉的例子：專案看板出現新任務，ChatGPT 讀任務連結的文件，先擬一份計畫。你回來看到的，已經是一份可以討論的初稿。

[DevDay 2026 精彩回顧](https://openai.com/zh-Hant/index/devday-2026-recap/)

不過這要外掛那端支援。開發者文件寫得很清楚：ChatGPT 支援的是**還在提議階段的 MCP Events 規格**，外掛的 MCP server 要列出自己有哪些事件、處理訂閱，再用 webhook 把事件送回來。光有一條 MCP 連線，不會自動變成這樣。目前能用的地方是 ChatGPT 網頁版的 Work 對話、桌面版選 Cloud 時的 Work 對話，以及 dots。

[MCP Events](https://developers.openai.com/plugins/build/mcp-events)

## Decisions API：先給選項，再讓模型選

**Decisions API** 是給開發者的快速選擇工具。你先定好問題跟有限的答案，再丟文字或圖片進去，讓 GPT-6 Luna 從這些選項裡挑一個。官方列的用途有三種：內容分類、請求分流、選 Agent 的下一步動作。

拿請求分流來說：先列好「帳務、技術、其他」三個選項，丟進一段客戶訊息，模型回「帳務」，你的程式就把它送進帳務流程。模型給的是一個選擇，後面怎麼處理，要靠你的系統接上。公布時是限量預覽。

[OpenAI Developers 在 X 的公告](https://x.com/OpenAIDevs/status/2105003318917697873)

如果你看過我講 JEV 那集，應該會覺得方向很眼熟：不叫 AI 寫一大段回答，只讓它專心做決定。

## GPT-6.1 Sol：同一筆預算，能多做多少

**GPT-6.1 Sol** 是新的工作模型，主打寫程式、操作電腦和專業工作。OpenAI 的說法是能力接近 GPT-6 Astra，標準輸入、輸出 Token 單價只有 Astra 的五分之一。比起模型名字又多一個小數點，這個我比較有興趣。

它瞄準哪些工作，看官方挑的評測就知道：DeepSWE 用真實程式庫裡的複雜工程任務來測；GDP.pdf 是丟一份塞滿表格、圖表、小字的專業 PDF，再問文件裡的問題。

[推出 GPT-6.1 Sol](https://openai.com/zh-Hant/index/introducing-gpt-6-1-sol/)

價格直接看表：

| 每 100 萬 Token | API 輸入 | API 輸出 | Codex 點數（輸入／輸出） |
| --- | --- | --- | --- |
| GPT-6 Astra | 10 美元 | 50 美元 | 250／1,250 點 |
| GPT-6.1 Sol | 2 美元 | 10 美元 | 50／250 點 |

[OpenAI API pricing](https://developers.openai.com/api/docs/pricing)

[Codex pricing](https://developers.openai.com/codex/pricing)

API 單價跟 ChatGPT 方案用量是兩套帳。但 Codex 的點數費率也是同樣的五倍差距，所以我手上這批點數拿去跑 Sol，同樣的點數能吃下的 Token 大約是 Astra 的五倍。

Sol 目前在 ChatGPT 工作和 Codex 裡開放給 Plus、Pro、Business、Enterprise、Edu，一般對話還沒有。要選哪個，我會先看同一件工作 Sol 能不能做對，再算完成它花了多少。

## 把 ChatGPT 方案帶去別的 App

最後一個跟荷包最有關。符合條件的 Plus、Pro 使用者，可以另外同意，讓 Notion、Devin、Vercel 這些參與的產品直接用你的 ChatGPT 方案用量。原本的訂閱，多了一個用的地方。

規則有三條要記：

- 這些 AI 請求會跟 **ChatGPT Work、Codex 共用同一份用量**，工具本身的訂閱或服務費另算。
- **登入跟同意使用方案是兩件事**。你可以只用 ChatGPT 登入，不讓它動你的方案；登入也不會把聊天紀錄或記憶送過去。
- 在 Settings → Usage 可以幫**每個 App 設週上限**。這是天花板，不是另外保留的額度。

[Using your ChatGPT plan in other apps and sites](https://help.openai.com/en/articles/20001542-using-your-chatgpt-plan-in-other-apps-and-sites)

Notion 的說明最具體：工作區是 Business 或 Enterprise，你本人有 ChatGPT Plus 或 Pro，連接之後在 **Notion Agent** 選特定 GPT 模型，這次對話就走 ChatGPT 方案；選 Auto 或其他模型，走 Notion 自己的點數。送出前，模型選單會標出這次用哪一份。ChatGPT 額度用完時，Notion Agent 會請你切回 Notion 點數繼續。Custom Agents 目前不適用。

[Use your ChatGPT plan with Notion Agent](https://www.notion.com/help/use-your-chatgpt-plan-with-notion-agent)

如果你 Codex 也用得很兇，先幫 Notion 設個週上限，免得一個工具先把整週吃光。

## 我怎麼看這次 DevDay

看完這次 DevDay，至少能把四件事分清楚：**dots 是誰持續在做、MCP Events 決定什麼時候開工、Decisions API 選下一步，還有工作到底從哪一份用量扣**。方案用量、點數、reset，各算各的。

我最期待的，還是能拿回一份真的能看的成果。至於我，62,500 點收到，開心啦，接下來就看這些點能做出什麼。你最想先試哪一項？還是跟我一樣，先去找 reset 在哪？
